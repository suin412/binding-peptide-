# M4 — 설계 + 분석 + 가상 스크리닝

## 목표
부모 서열에서 변이체를 만들고, 원본과 비교하고, 가상 라이브러리를 필터·순위화하는 스크리닝 흐름을 완성한다. (PRD 시나리오 2·4, 구조 예측 제외)

## 범위
- 포함: 변이 파서·적용, 알라닌 스캐닝 등 라이브러리 생성, 정렬, 물성 비교, 소수성 플롯, 필터 깔때기, 점수화, 순위화, 변이체 저장·내보내기
- 선택/후순위: 융합(링커), 보존 치환 제안, Helical wheel, 구조 기반 재순위화(A-7, 구조 마일스톤 이후 연결)

## 산출물

## 완료 기준
- 알라닌 스캐닝으로 변이체 생성 → 원본과 정렬(동일성·차이 위치)·물성·소수성 플롯 비교 (시나리오 2)
- 잘못된 변이 입력(범위 초과, 잔기 불일치)에 명확한 오류 메시지
- 라이브러리 생성 → 필터 깔때기 → 순위화 → 상위 후보 저장 (시나리오 3b, 구조 단계 제외)
- 1,000개 후보 필터링이 체감상 즉시 완료된다
- 구조 기반 재순위화를 끈 상태에서 전체 흐름이 정상 동작한다

## 테스트
- `mutate.py`: 모든 변이 유형 정상 적용, 오류 케이스(범위 초과/잔기 불일치/문법 오류), 알라닌 스캐닝 개수·위치(이미 Ala인 위치 처리), 셔플 시드 재현성
- `align.py`: 동일 서열 100%, 점돌연변이 1개, 삽입·삭제
- `screen.py`: 필터 경계값, 깔때기 단계별 개수 합리성, 빈 결과 처리

## 리스크
- 필터 기본값이 임의적 → 슬라이더 기본값은 부모 서열 기준 상대값으로 제안
- 점수식이 실제 활성과 무관함을 사용자가 오해 → 문구와 도움말로 명시
- 범위 확대(융합, Helical wheel) → P1/P2는 P0 완료 후에만
