## 1. 배경 및 문제 정의

펩타이드/단백질 설계를 배우려면 (1) 공개된 서열을 찾고, (2) 그 서열이 **어떻게 발굴되었고 무엇에 결합하는지** 근거를 확인하고, (3) 서열을 변형해 새 후보를 만들고, (4) 물성과 3D 구조로 결과를 살펴보는 과정을 여러 사이트와 도구를 오가며 수행해야 한다. 특히 다음 문제가 있다.

- 펩타이드(특히 표면 결합 펩타이드, 합성 펩타이드)는 **UniProt에 없는 경우가 많고**, 논문 본문이나 특허 서열목록에만 존재한다.
- 서열만 복사하면 **출처·발굴(스크리닝) 방법·결합 대상 같은 맥락이 사라진다.** 맥락 없는 서열은 설계 연습의 출발점으로 부적절하다.
- 서열 설계 → 물성 → 구조 확인이 도구마다 분리되어 있어 학습 흐름이 끊긴다.

## 2. 제품 목표와 비목표

### 목표
1. 하나의 앱에서 **검색 → 서열 확보(+근거 기록) → 변이/스크리닝 설계 → 물성 분석 → 구조 확인**을 끝까지 체험할 수 있게 한다.
2. UniProt에 없는 펩타이드도 **논문·특허에서 서열을 찾아 출처와 함께** 가져올 수 있게 한다.
3. 모든 서열에 **발굴 방법과 결합 대상**을 붙여 보여주고, 모르는 정보는 "미보고"로 정직하게 표시한다.
4. 코드와 UI가 단순해서 학습·수정이 쉬운 **연습용 도구**로 유지한다.

### 비목표 (v1 범위 밖)
- 신약/소재 설계의 실사용 수준 예측 정확도 보장
- ML 기반 서열 설계(ProteinMPNN/ESM 등), 도킹·결합 친화도 예측
- 결합 친화도의 **정량 예측**(Kd 절대값), 분자동역학·도킹 계산, 발굴 방법·친화도의 자동 확정 (친화도는 문헌 값 기록과 학습용 경험적 점수까지만 v1.1에 포함)
- 로컬 GPU 구조 예측, 사용자 계정·서버 배포·다중 사용자 협업
- 논문·특허 본문의 저장·재배포 (서열과 출처 식별자만 저장)

## 3. 대상 사용자

| 페르소나 | 설명 | 핵심 니즈 |
|---|---|---|
| 학습자 (주 사용자) | 펩타이드/단백질 설계를 배우는 학생·연구 입문자 (본인 포함) | 전체 흐름을 쉽게 반복 연습, 결과의 의미 이해 |
| 탐색자 | 특정 소재/표적에 결합하는 펩타이드를 문헌에서 찾아보려는 사용자 | 논문·특허에서 서열+근거를 빠르게 모으기 |

사용 환경: Windows PC, Python 3.11, 로컬에서 `streamlit run`으로 실행, 인터넷 연결 필요(공개 API).

## 4. 사용자 시나리오

1. **DB에 있는 단백질**: "melittin" 검색 → 서열·물성 확인 → 알라닌 스캐닝 변이체 생성 → 원본/변이체 구조 비교(RMSD는 선택).
2. **DB에 없는 펩타이드(논문)**: UniProt 결과 없음 → 논문 검색 → 후보 서열 추출 → 확인·채택 → 출처(PMID), 발굴 방법(예: 파지 디스플레이), 결합 대상(예: 티타늄) 확인 → 변이체 설계.
3. **특허 서열**: 특허번호/키워드 검색 → `SEQ ID NO` 서열 후보 → 채택 및 출처 기록 (접근 불가 시 본문 붙여넣기).
4. **가상 스크리닝**: 부모 서열에서 가상 라이브러리 생성 → 필터 깔때기 → 순위화 → (선택) 상위 후보 구조 예측으로 재순위화.

| A-8 | **표면 결합 성향 점수(학습용 예측)**: 표면 분류 6종(소수성 고분자, 티타늄·금속 산화물, 귀금속, 실리카, 하이드록시아파타이트, 탄소 소재)별 잔기 가중치로 서열을 점수화해 무작위 대비 백분위·가중치 척도(0–100)·잔기별 기여를 보여준다. **절대 친화도(Kd) 예측이 아님을 화면에 항상 명시**하고, 스크리닝 점수에 선택적 가중치(기본 0)로 반영할 수 있다 | P1 |
| R-1 | **자동 서열 추천**: 결합 대상(표면 6종 중 하나)을 고르면 결합 성향이 높을 것 같은 새 서열을 자동으로 추천한다. 사용자는 변이·무작위 서열을 만들지 않는다. 점수 = 표면 가중치 점수 + 기존 결합 서열(문헌 예시 + 내 서열)과의 잔기 구성 유사도, 용해도·응집 제약은 벌점. 후보끼리 잔기 구성이 서로 다르게 고르고(순서만 다른 복사본 제외), 기존 서열의 복사본은 제외하며, 같은 설정은 재현된다 | P0 |
| R-2 | 추천 화면은 **Kd 예측이 아님**을 항상 명시하고, 기존 결합 서열 자신의 점수(기준선)를 함께 보여주며 기준선이 낮은 표면에서는 신뢰할 수 없다는 경고를 띄운다. 추천 서열은 "설계된 서열(비실험)"로 저장하고 결합 대상·친화도를 상속·주장하지 않는다 | P0 |
| R-3 | **새 서열의 분석**: 추천된 후보(두 추천 탭 모두)는 저장하지 않아도 물성 비교를 바로 볼 수 있어야 한다(구조 예측은 2026-10-12 제거) | P0 |
| R-4 | 사용자가 가진 새 서열은 분석·구조 탭에서 바로 입력(검증 포함)해 곧바로 분석·예측 대상으로 쓸 수 있어야 한다 | P0 |
| R-5 | **개선형 추천(🔧)**: 채택한 서열 하나와 표면을 고르면, 최대 k개(기본 3) 위치만 치환한 변이체 중 점수가 부모보다 오르는 것을 자동 추천한다. 바꾸지 않을 위치를 지정할 수 있고, 바꾼 잔기당 비용을 물려 적게 바꾸는 쪽을 우선하며, 후보끼리 3곳 이상 다르게 고른다. 점수가 오르는 변이가 없으면 "이미 국소 최적"이라고 알린다. 저장하면 부모에 연결된 설계된 서열(변이체)이 된다 | P0 |
| R-6 | **알려진 전체 서열 기반 추천(🎯)**: 표면별 알려진 결합 서열 목록(문헌 예시 + 내 서열)을 보여주고 참고할 서열을 고르게 한다(결합 대상 미기록 서열을 포함할 수도 있음). 유사도는 잔기 구성과 연속 2-mer 모티프를 함께 보며, 알려진 서열의 재조합에서 탐색을 시작한다 | P0 |
| R-7 | 구조 탭과 구조 예측(ESMFold) 화면은 두지 않는다(2026-10-12 제거). 추천 결과는 물성 비교까지만 제공한다 | P0 |
| R-8 | **결과 엑셀 내보내기**: 내 서열(출처·발굴 방법·결합 대상·친화도·물성), 결합 성향 점수, 친화도 기록, 예측 vs 보고값, 두 추천 탭의 결과(저장 전이라도)를 한 `.xlsx` 파일로 내려받는다. 점수는 Kd 예측이 아니라는 안내를 파일에 포함한다 | P0 |

## 6. 비기능 요구사항

- **정직한 표시**: 모르는 값은 "미보고/미확인"으로 표시하고 추정해서 채우지 않는다. 자동 추출 값은 확정 전까지 시각적으로 구분한다.
- **신뢰성**: 외부 API에 타임아웃·재시도·사용자 친화적 오류 메시지를 적용하고, 응답은 `data/cache/`에 캐시한다.
- **성능**: 검색 응답 표시 5초 이내(캐시 미스 기준, API 상태 영향), 라이브러리 필터링은 1,000개 후보에서 1초 이내, ESMFold 호출은 비동기 진행 표시.
- **저작권/약관**: 논문·특허는 서열·식별자·짧은 발췌(1문장 이내)만 저장한다. 본문은 PMC/Europe PMC가 API로 제공하는 것만 읽고 메모리에서 서열만 추출하며 디스크에 저장·재배포하지 않는다. 제공되지 않는 본문(유료 등)은 가져오지 않고 링크만 제공한다. 사이트 약관상 스크래핑이 금지된 곳은 연동하지 않는다.
- **프라이버시**: 검색 시 입력한 키워드는 외부 API(UniProt·Europe PMC)로 전송된다(구조 예측 제거로 서열은 구조 서버로 전송되지 않음). 미공개/독점 서열 입력 주의 문구를 표시한다.
- **유지보수성**: UI(`app.py`)와 로직(`src/`) 분리, 로직은 Streamlit 없이 단위 테스트 가능.
- **환경**: Windows, Python 3.11, 추가 시스템 설치 없이 `pip install -r requirements.txt`로 실행.

## 8. 외부 의존성

UniProt REST, RCSB PDB, AlphaFold DB, ESMFold API, Europe PMC, NCBI E-utilities, 특허 서열 공개 데이터(NCBI/EBI), (선택) APD3·DRAMP. 모두 무료·키 불필요. 장애·스키마 변경·ESMFold 공개 API 제한이 위험 요소다 (10장).

## 9. 성공 지표 (연습용 기준)

- 시나리오 1~4와 비표준 잔기 케이스를 **수동 점검에서 끝까지 완료**할 수 있다.
- 논문 기반 예시 3건에서 서열 후보 추출 시 사용자가 기대한 서열이 후보 표에 포함된다 (재현율 목표 ≥ 80%, 오탐은 사용자 검토로 걸러짐).
- 맥락 정보가 없는 항목이 "미보고"로 표시되고, 값이 임의로 채워지는 경우가 0건이다.
- 핵심 로직(변이, 물성, 서열 추출기, 결합 대상 키워드 매칭) 단위 테스트 통과.
