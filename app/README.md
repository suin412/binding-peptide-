# PepLab — 펩타이드/단백질 설계 연습 앱

공개된 펩타이드·단백질 서열을 **찾고(검색) → 근거와 함께 가져오고 → 알려진 서열을 개선하거나 알려진 전체 서열을 바탕으로 새 서열을 자동 추천받고 → 물성을 분석해 본다**하는 학습용 Streamlit 앱입니다. 신약/소재 설계용 도구가 아니라 흐름을 익히는 연습용입니다.

문서: [PRD](docs/PRD_1test.md) · [계획](docs/PLAN_1test.md) · [마일스톤별 개발 문서](docs/development/README.md)

## 설치와 실행 (Windows, Python 3.11)

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열립니다. 외부 공개 API(UniProt, Europe PMC, NCBI PMC)를 쓰므로 인터넷 연결이 필요합니다.

테스트 (네트워크 없이 실행됩니다):

```bash
.venv\Scripts\python.exe -m pytest -q
```

## 탭 구성

| 탭 | 하는 일 |
|---|---|
| 🔎 검색 | ① UniProt 검색 → ② 키워드로 **여러 논문(전 기간)의 서열을 바로 찾기** · 텍스트 붙여넣기(논문 본문·특허) · 논문 이름 검색(선택) → ③ 직접 입력·FASTA·예시 프리셋 |
| 🔧 개선형 추천 | 채택한 서열 **하나를 골라** 몇 개 잔기만 바꿔 결합 성향 점수를 높일 수 있는 **개선형**을 자동 추천 (바꾸지 않을 위치 지정 가능) |
| 📊 서열 분석 | 물성 비교, 서열 정렬, 소수성·조성·helical wheel |
| 🧲 결합 친화도 | ① 표면 결합 성향 점수(학습용 예측) ② 논문에서 보고된 Kd·ΔG·측정 방법 기록(본문 값 후보 찾기 포함) ③ 예측 vs 보고값 비교 |
| 🎯 전체 서열 기반 추천 | 결합 **대상(표면)** 을 고르면 **알려진 결합 서열 전체**(문헌 예시 + 내 서열, 참고할 서열 선택 가능)를 바탕으로 **새 서열을 자동 추천** |

사이드바에서 현재 서열을 고르고, 발굴 방법·결합 대상을 편집하고, FASTA/CSV로 내보낼 수 있습니다.

## 핵심 원칙

- **출처 기록**: 모든 서열에 출처(UniProt AC, PMID/DOI, 특허번호·SEQ ID NO)를 붙여 보여줍니다.
- **발굴 방법은 직접 선택**: 논문을 읽고 목록(파지 디스플레이, 기능 기반 HTS 등)에서 고릅니다. 자동 추출하지 않습니다.
- **결합 대상은 제안 → 확정**: 텍스트의 소재 키워드(titanium, gold 등)로 후보를 *제안*하고, 근거 문장을 보여준 뒤 사용자가 확정합니다.
- **모르면 "미보고"**: 값을 추측해서 채우지 않습니다. 결합 친화도는 **논문에 보고된 값**만 기록하고(미보고면 "미보고"), 예측 점수는 **학습용 경험적 점수**로만 보여줍니다.
- **자동 채택 금지**: 논문·특허에서 추출한 서열 후보는 항상 직접 확인하고 채택합니다.
- **추천·설계된 서열은 "설계된 서열(비실험)"**: 결합이나 친화도가 측정된 것이 아니며, 추천 대상과 예상 점수는 참고 정보로만 기록됩니다.

## 학습 시나리오

### 1. DB에 있는 단백질: 멜리틴
1. 검색 ▸ ① UniProt에서 `melittin` 검색 → P01501(70 aa 전구체)과 P01504(26 aa)를 비교해 보고, **사용할 구간**에서 성숙 펩타이드를 고릅니다.
2. "이 서열 사용" → 상단 헤더에서 출처와 "미보고" 표시를 확인합니다. 분석 탭에서 pI·순전하·GRAVY를 봅니다.
3. 분석 탭에서 여러 서열을 골라 물성·서열 정렬·소수성 프로파일을 비교합니다.
4. 서열 분석 탭에서 물성을 비교하고 서열을 정렬해 봅니다.

### 2. UniProt에 없는 펩타이드: 논문·특허에서 찾기
1. 검색 ▸ ②에서 영어 키워드(예: `titanium binding peptide`)를 넣고 **서열 찾기**를 누릅니다. 논문을 고르지 않아도, 여러 논문(기본 100편)의 초록에서 찾은 서열이 **표로 바로** 나옵니다.
2. 기본은 1975년~현재 **전 기간**을 연도 구간별로 고르게 가져옵니다(Europe PMC 기본 정렬은 최근 논문 쪽으로 치우쳐 있어서입니다). 범위·논문 수·정렬 방식은 "검색 범위 설정"에서 바꾸고, "연도별 분포"로 전 기간이 포함됐는지 확인할 수 있습니다. **초록만이 아니라 논문 본문(전문)까지 읽습니다** — 서열은 대부분 본문(방법·결과·표)에 있기 때문입니다. 논문당 수 초가 걸리고 3편씩 동시에 읽으며, 제목·초록에 peptide·binding·찾는 재료가 나오는 논문부터 읽습니다. PMC에 본문이 공개된 논문(오픈액세스 + NIH 저자 원고 등)이 대상이고, Europe PMC가 막혀 있으면 NCBI PMC로 다시 시도합니다. 읽지 못한 논문은 목록과 링크로 보여줍니다. 전체 일치 논문이 설정한 수(기본 3,000편) 이하이면 전부 가져옵니다.
   - **재료 약어는 자동으로 확장**됩니다. 예를 들어 PET binding peptide의 PET은 플라스틱(폴리에틸렌 테레프탈레이트)인데 그대로 검색하면 양전자방출단층촬영(PET 영상) 논문이 대부분이라, 정식 명칭으로 바꾸고 영상 논문을 제외합니다. 실제 검색식은 결과의 접이식 칸에서 확인하고, 설정에서 끌 수 있습니다. 따옴표·괄호·AND/OR/NOT를 직접 쓰면 그대로 검색합니다.
3. 같은 서열이 여러 논문에 나오면 한 줄로 묶어 논문 수·연도를 보여줍니다. **여러 서열을 한꺼번에 선택**할 수 있습니다(표에서 여러 행 클릭, 목록에서 여러 개 선택, 또는 "표시된 후보 전부 선택"). 하나만 고르면 출처 논문을 고르고 문맥·서열을 확인·수정한 뒤 채택하고, 여러 개를 고르면 서열마다 자기 논문을 출처로 기록하면서 발굴 방법은 공통으로 적용해 한 번에 채택합니다. 결합 대상은 "논문별 제안 1순위(제안 상태)", "모두 같은 대상으로 직접 입력", "미보고" 중에서 고릅니다. `MEDLINE` 같은 일반 약어일 수 있는 후보는 "문맥 불확실"로 표시되어 기본으로 숨겨집니다.
4. 발굴 방법을 목록에서 고르고, 그 논문에서 제안된 결합 대상 후보를 확인해 "확정"합니다. 출처는 PMID로 기록됩니다. 논문 제목으로 특정 논문을 찾고 싶으면 "논문 이름으로 검색 (선택)" 모드를 쓰세요.
5. 특허는 [Google Patents](https://patents.google.com/) 등에서 본문/서열목록을 복사해 `텍스트 붙여넣기`에 넣으면 `<400>` 서열목록과 `SEQ ID NO`를 읽습니다. 연습용 가상 샘플 텍스트가 들어 있습니다.
6. **서열 → 논문**: "서열로 논문 찾기" 모드에 서열을 넣으면(현재 선택한 서열이 기본값) Europe PMC의 본문 색인에서 그 서열이 나온 논문·특허를 찾고, 초록과 본문(PMC 공개분)을 읽어 **어느 문맥에 나오는지**(정확히 일치 / 더 긴 서열에 포함 / 3문자 표기)를 보여줍니다. 찾은 논문을 출처로 바로 채택할 수 있고(특허는 "특허"로 기록), 그 논문에서 제안된 결합 대상 후보도 함께 보입니다. 서열이 본문 표·그림·보충자료에만 있으면 "위치 미확인"으로 표시됩니다.
7. `Aib`, `Orn`, D-아미노산, `Ac-`/`-NH2` 같은 비표준 요소는 가장 가까운 표준 잔기로 단순화되고 원문 표기가 메모로 남습니다.
### 3. 채택한 서열 하나를 개선하기 (🔧 개선형 추천)
1. 채택한 서열 중 **개선할 서열 하나**를 고릅니다(서열이 없으면 위의 ➕ 새 서열 직접 입력으로 바로 넣을 수 있습니다). 서열에 결합 대상이 기록돼 있으면 그 표면이 기본으로 선택되고, 없으면 직접 고르라는 안내가 뜹니다.
2. **최대 변이 수**(바꿀 잔기 개수, 기본 3)와 추천 개수를 정하고, 알려진 활성 모티프처럼 **바꾸지 않을 위치**(예: `1-3, 7`)가 있으면 적습니다.
3. "개선형 추천 받기"를 누르면 부모에서 최대 k개 위치를 치환한 변이체를 빔 탐색으로 훑어 **점수가 부모보다 오르는 변이**를 골라 줍니다. 서로 3곳 이상 다른 후보만 고르고, 바꾼 잔기 하나당 2점의 비용을 물려 적게 바꾸는 쪽을 우선합니다.
4. 결과 표에는 변경(예: `D5R P7R`), 변이 수, 예상 결합 성향, **부모 대비** 점수, 변이별 표면 가중치 변화가 나옵니다. 점수가 오르는 변이를 못 찾으면 "이미 (국소) 최적"이라고 알려 줍니다(실제로 나쁜 서열이 아니라는 뜻).
5. 고른 개선형을 "내 서열에 추가"하면 **그 서열의 변이체**(부모 연결, 설계된 서열, 비실험)로 저장되어 📊 서열 분석에서 부모와 정렬·비교할 수 있습니다.

### 4. 알려진 전체 서열을 바탕으로 새 서열 추천 (🎯 전체 서열 기반 추천)
1. **결합 대상(표면)** 을 고릅니다. 현재 서열에 결합 대상이 기록돼 있으면 그 표면이 기본으로 선택됩니다. 길이 범위와 추천 개수를 정합니다.
2. **참고할 알려진 서열 목록**이 표면별로 나옵니다: 문헌에서 확인한 서열(폴리머 4개, 티타늄 3개) + 내가 채택한 서열 중 이 표면에 결합한다고 기록한 것. 기본은 전부 참고하고, 원하는 것만 고를 수 있으며, 결합 대상을 기록하지 않은 내 서열도 후보로 볼 수 있습니다.
3. "서열 추천 받기"를 누르면 진화적 탐색으로 후보를 만들고 점수로 골라 **서로 잔기 구성이 다른 새 서열**을 보여줍니다. 변이나 무작위 서열을 직접 만들 필요가 없고, 같은 설정이면 결과가 재현되며 "다른 후보 더 보기"로 다른 후보를 볼 수 있습니다.
4. 점수는 ① 그 표면의 잔기 가중치 점수와 ② **알려진 서열 전체와의 유사도**(잔기 구성 + 알려진 서열에 있는 연속 두 잔기 모티프)를 합친 값이고, 용해도·응집 위험 같은 제약 위반은 벌점으로 깎습니다. 알려진 서열을 섞은(재조합) 후보에서 탐색을 시작하며, 알려진 서열과 거의 같은 복사본은 추천하지 않습니다.
5. **기준선 확인**: 알려진 서열 자신이 이 점수에서 몇 점인지 함께 보여줍니다. 알려진 결합 서열의 점수가 낮은 표면(예: 티타늄)에서는 점수가 실제 결합 특징을 잘 못 잡는다는 경고가 뜹니다 — 그럴 땐 "닮은 정도의 반영 비중"을 올려 알려진 서열 쪽에 무게를 두세요.
6. 마음에 드는 후보를 여러 개 골라 "내 서열에 추가"하면 설계된 서열(비실험)로 저장됩니다.

### 두 추천 탭 공통
- 추천 결과 아래에서 **저장하지 않아도** 전체 후보의 물성(분자량·pI·순전하·GRAVY·불안정성 지수)을 비교할 수 있습니다(개선형 추천에서는 부모도 함께 표시). 구조 예측 기능은 없습니다.
- 직접 가진 새 서열은 개선형 추천·서열 분석 탭 맨 위의 **➕ 새 서열 직접 입력**에 넣으면 바로 분석·개선형 추천 대상이 됩니다.

### 결과를 엑셀로 내보내기
사이드바 위쪽과 각 탭(개선형 추천·전체 서열 기반 추천·서열 분석·결합 친화도)의 **📥 전체 결과 엑셀(.xlsx) 내보내기** 버튼을 누르면 한 파일로 내려받습니다. 파일에는 다음 시트가 들어갑니다.

| 시트 | 내용 |
|---|---|
| 안내 | 생성 시각, 점수가 휴리스틱이라는 주의, 어떤 시트가 들어 있는지 |
| 내 서열 | 서열·출처·발굴 방법·결합 대상·보고된 친화도·물성(분자량, pI, 순전하, GRAVY …)·설계 참고 |
| 결합 성향 점수 | 내 서열 전체의 표면 6종별 결합 성향(가중치 척도) |
| 결합 친화도 | 문헌에서 보고된 값과 계산값을 구분한 기록, ΔG |
| 예측 vs 보고값 | 점수와 보고된 친화도 비교, 순위상관 ρ |
| 개선형 추천 | (실행한 경우) **실행할 때마다 쌓인 모든 기록**: 부모와 개선형 후보, 변경, 부모 대비 점수, 표면 가중치 변화 (실행 번호·시각 열로 구분) |
| 전체 서열 기반 추천 · 참고한 알려진 서열 | (실행한 경우) 모든 실행 기록의 추천 후보와 참고한 알려진 서열의 기준선 점수 |
| 논문 검색 결과 | (검색 탭에서 서열을 찾았다면) 서열, 나온 논문 수·연도, 대표 논문, 결합 대상 후보(제안, 미검증), 경고 |

**결과마다 따로 저장하지 않고 한 파일에 모두 담깁니다.** 추천을 여러 번 실행해도 앱을 켜 둔 동안의 모든 실행이 한 시트에 쌓여 있으며(앱을 끄면 기록은 사라집니다), 추천 결과를 "내 서열에 추가"하지 않아도 내보낼 수 있습니다. 엑셀 라이브러리 없이 앱이 직접 `.xlsx`를 만들며, 값은 점수이지 Kd 예측이 아닙니다.


## 결합 친화도: 무엇을 하고 무엇을 하지 않나
- **예측 점수 (학습용)**: 표면 화학별 정성적 경향(소수성 고분자 ← W·F·Y·H, 티타늄·실리카 ← R·K, 하이드록시아파타이트 ← D·E, 귀금속 ← H·C·M·W, 탄소 소재 ← 방향족)을 잔기 가중치로 단순화해 서열을 줄 세웁니다. 결과는 같은 길이 무작위 서열 대비 백분위(강한 후보끼리는 100 근처로 몰림)와 가중치 척도(0–100)로 보여줍니다. **Kd를 예측하지 않습니다.** pH·이온 세기·표면 상태·펩타이드 입체 구조는 반영하지 않습니다.
- **보고된 친화도 기록**: Kd·Ka·ΔG·계산 결합 에너지·기타를 값, 단위, 측정 방법(QCM-D, SPR, BLI, ITC …), 조건, 출처와 함께 기록합니다. Kd는 ΔG=RT·ln(Kd) (298 K)로 환산해 비교합니다. 본문을 붙여넣으면 값 후보를 찾아 폼을 채워 주지만 어느 펩타이드의 값인지는 알 수 없어 "제안" 상태로만 들어갑니다. 변이체에는 상속되지 않습니다.
- **비교**: 예측 점수와 보고값의 순위상관(ρ)을 보여줍니다. 문헌 예시(PMID 37735840의 PET·PE·PP·PS 설계 펩타이드, PepBD **계산** 점수)로 연습할 수 있는데, 이 4개에서는 예측이 4개 모두를 "플라스틱 결합 성향 높음"으로 올바르게 분류하지만 서로의 순서는 맞히지 못합니다(ρ≈0.2, n=4라 의미 없음). 즉 이 점수는 **결합할 만한 서열인지 거르는 용도**이지 강도를 순위 매기는 용도가 아닙니다.
- 두 추천 탭은 이 표면 점수를 쓰되, 점수만 최대화하면 W만 12개 같은 비현실적 서열이 나오므로 용해도·응집 제약을 함께 걸어 현실적인 후보만 남깁니다.
- 분자동역학·도킹 등 정량 계산은 하지 않습니다(서열 하나에 수 시간~수 일).

## 한계와 주의

- 특허 사이트는 약관상 자동 수집을 하지 않습니다. 직접 찾아 붙여넣는 방식입니다.
- 논문·특허 본문은 저장하지 않고 서열·식별자·짧은 근거 문장만 다룹니다. 유료 전문은 가져오지 않습니다.
- 서열 추출·소재 매칭은 정규식/키워드 기반이라 오탐과 누락이 있습니다 (이미지·표로 된 서열은 읽지 못합니다). 본문은 PMC에 공개된 논문만 읽을 수 있고(유료 논문은 초록만), 본문 읽기는 논문당 수 초가 걸립니다. 본문 텍스트는 메모리에서 서열만 추출하고 저장하지 않습니다.
- matplotlib 그림의 한글은 Windows의 `Malgun Gothic` 등 한글 폰트가 있어야 정상 표시됩니다.
- 순전하는 Biopython `charge_at_pH(7.4)` 추정값이며 말단 변형(아세틸화·아마이드화)은 반영하지 않습니다.

## 파이썬 없이 실행하기 (휴대용 버전)
파이썬이 없는 Windows PC에서는 `PepLab_portable.zip`을 풀고 **`PepLab 실행.bat`** 을 더블클릭하면 됩니다. 파이썬 실행기와 필요한 패키지가 폴더 안(`runtime`)에 들어 있고, 앱 소스는 `app`에 있습니다. 몇 초 뒤 브라우저에서 http://localhost:8501 이 열리며, 끝낼 때는 검은 창을 닫으면 됩니다. 검색은 인터넷이 필요합니다.

```
app.py                 Streamlit 진입점(사이드바 + 5개 탭: 검색·개선형 추천·서열 분석·결합 친화도·전체 서열 기반 추천)
src/
  sequence.py          서열 정리·검증, FASTA, 3문자 코드 변환
  provenance.py        SeqRecord (서열 + 출처 + 발굴 방법 + 결합 대상)
  presets.py           예시 프리셋(UniProt에서 확인한 서열) + 가상 샘플 텍스트
  sources/             UniProt, Europe PMC, AlphaFold DB 클라이언트, 서열 후보 추출, 소재 키워드 제안, HTTP 캐시
  design/recommend.py  알려진 전체 서열 기반 자동 서열 추천 (진화적 탐색 + 유사도·제약)
  design/improve.py    서열 하나의 개선형 추천 (빔 탐색, 고정 위치, 변이 비용)
  design/mutate.py     변이 파서·라이브러리 생성 — 화면에서는 쓰지 않음(코드·테스트만 보존)
  analysis/            물성, 정렬, 그림, 결합 성향 점수, 스크리닝 필터·점수(화면에서는 쓰지 않음)
  export.py            결과를 엑셀(.xlsx)로 만드는 코드 (외부 라이브러리 없음)
  structure/           (화면에서 쓰지 않음) ESMFold·PDB 유틸·3D 뷰어 코드 보존
  ui/                  탭별 Streamlit 화면
tests/                 단위 테스트 + 화면 흐름 테스트(AppTest), fixtures/
data/cache/            API 응답 디스크 캐시 (삭제해도 됨)
```
