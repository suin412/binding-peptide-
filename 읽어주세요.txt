PepLab 배치 파일 버전 (파이썬 설치 불필요, Windows 전용)

■ 사용법
 1. 이 폴더(PepLab_배치)를 통째로 쓰세요. 다른 곳으로 옮길 때도 폴더 전체를 옮기세요.
    (zip으로 받았다면 우클릭 → "모두 압축 풀기"로 먼저 푸세요. zip 안에서 바로 실행하지 마세요.)
 2. 폴더 안의 "PepLab 실행.bat" 을 더블클릭하세요.
 3. 검은 창이 뜨고, 서버가 준비되면(보통 몇 초, 처음에는 1~2분까지) 기본 브라우저에서 PepLab이 자동으로 열립니다.
    안 열리면 검은 창에 적힌 주소(보통 http://127.0.0.1:8501)를 브라우저 주소창에 입력하세요.
 4. 끝낼 때는 검은 창을 닫으세요. (검은 창을 닫으면 앱도 꺼집니다)

■ 알아둘 점
 - "PepLab 실행.bat" 만 따로 복사하거나 다운로드하면 실행되지 않습니다. runtime 폴더와 app 폴더가 같은 폴더 안에 있어야 합니다.
   (바탕화면에 두고 싶으면 bat 파일의 바로가기를 만들어 옮기세요.)
 - 폴더 안의 파일이나 하위 폴더(특히 runtime 안의 폴더)를 지우거나 정리하지 마세요. 앱이 실행되지 않을 수 있습니다.
 - 검색(UniProt, Europe PMC)은 인터넷 연결이 필요합니다. 논문 본문까지 읽는 검색은 몇 분 걸릴 수 있습니다.
 - 8501 포트가 이미 쓰이고 있으면 자동으로 8502, 8503 ... 중 빈 포트를 씁니다. 주소는 검은 창에 표시됩니다.
 - Windows가 "PC를 보호했습니다" 창을 띄우면 "추가 정보 → 실행"을 누르세요. 백신이 막으면 이 폴더를 예외로 허용하세요.
 - 폴더 경로가 너무 길면(약 250자 이상) 압축이 덜 풀릴 수 있으니 바탕화면 같은 짧은 경로에 푸세요.
 - 앱을 끄면 저장하지 않은 서열과 추천 기록은 사라집니다. 필요한 결과는 화면의 "전체 결과 엑셀 내보내기"로 저장하세요.
 - 검색 결과 캐시는 app\data 폴더에 쌓입니다.
 - 자세한 설명: app\README.md, app\docs\PepLab_보고서.html
