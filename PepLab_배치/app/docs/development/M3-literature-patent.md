# M3 — 논문·특허 검색, 서열 후보 추출, 발굴 방법/결합 대상

## 목표
UniProt에 없는 펩타이드를 논문·특허에서 찾아 서열 후보를 추출하고, 사용자가 확인·채택하게 한다. 채택한 서열에는 출처, 발굴 방법(선택 목록), 결합 대상(키워드 제안 + 사용자 확정)을 붙인다. (PRD 시나리오 2·3, 표면 결합 펩타이드 지원)

## 범위
- 포함: Europe PMC 초록 검색, 서열 후보 추출기, 후보 검토·채택 UI, 특허 본문 붙여넣기 경로, 결합 대상 키워드 제안, 비표준 문자 경고
- 제외: 오픈액세스 전문 XML 자동 파싱(후순위), 특허 사이트 다중 연동, PDB·펩타이드 DB 검색(P2), 결합 친화도·측정 방법 기록(향후 확장), 발굴 방법 자동 추출

## 작업 목록
- [ ] 시작 전: Europe PMC `search` 응답 확인(초록 포함 여부), **특허 서열 공개 소스(NCBI/EBI) 접근 가능성 확인** — 가능한 소스가 없으면 특허는 "붙여넣기 + 외부 링크"만 구현 (PRD 12장 미결 사항 해소)
- [ ] `src/sources/europepmc.py`: 키워드 검색 → 제목, 저자, 저널, 연도, PMID/DOI, 초록, OA 여부. 캐시·재시도 적용
- [ ] `src/sources/seqextract.py` — 텍스트에서 서열 후보 추출
  - (a) 1문자 표기: 표준 20 아미노산으로만 이뤄진 길이 5~100 연속 문자열. 일반 영단어 대문자열·약어 제외 규칙(대소문자·길이·아미노산 조성 기준)
  - (b) 3문자 표기: `Gly-Ile-Gly-…`, `Gly Ile Gly` → 1문자 변환
  - (c) `SEQ ID NO: n` 근처의 서열과 번호 연결
  - 각 후보에 위치(문단/오프셋)와 짧은 문맥을 함께 반환
  - 비표준 요소 탐지: 표준 20자 외 문자(`X`, `Aib`, `Orn`, `Nle`, 소문자 d- 표기 등)를 경고 대상으로 반환
- [ ] 검색 탭 "논문/특허" 영역
  - 논문: 검색 → 결과 목록 → 선택한 논문의 초록에서 후보 추출 → 후보 표
  - 특허/기타 텍스트: 본문 붙여넣기 → 후보 추출 → 후보 표 (`SEQ ID NO` 포함), 특허 검색용 외부 링크(Google Patents 등) 제공
  - 후보 표에서 행 선택 → 서열 수정 가능 → "채택" (자동 채택 금지, F-5)
- [ ] 채택 시 `SeqRecord` 생성: 출처 유형(논문/특허), 식별자(PMID·DOI·특허번호·SEQ ID NO), URL, 확인 일자
- [ ] 비표준 요소 경고: 감지 시 "표준 서열로 단순화됨 / 구조 예측에서 무시됨" 경고 + 원문 표기를 `nonstandard_notes`에 보존 (F-10)
- [ ] `src/sources/binding.py`: 소재 키워드 사전(titanium/Ti, gold/Au, silica/SiO2, polystyrene, hydroxyapatite, graphene, stainless steel 등, 동의어 포함)으로 결합 대상 **후보** 제안 + 근거 문장 1개
- [ ] 결합 대상 UI: 후보 선택 또는 직접 입력 → 명칭·분류(목록)·형태/조건 메모 → "확정". 상태 표시(제안/확정/미보고)
- [ ] 발굴 방법 선택 컴포넌트(M2) 재사용
- [ ] 서열 헤더 요약 문장: "이 펩타이드는 [대상]에 결합, 발굴 방법: [방법]" (없으면 "미보고")
- [ ] 논문/특허 기반 입력 연습용 프리셋 1~2개 추가 (실제 논문의 서열은 **직접 원문에서 확인한 것만** 사용)
- [ ] UniProt 결과 없음 → "논문에서 찾아보기" 버튼 활성화 (M2의 자리 연결)

## 산출물
`src/sources/europepmc.py`, `seqextract.py`, `binding.py`, 논문·특허 UI, 결합 대상 입력 UI, fixture(`europepmc_*.json`, 샘플 초록/특허 텍스트), 테스트

## 완료 기준
- UniProt에 없는 펩타이드 키워드 → 논문 검색 → 초록에서 후보 추출 → 채택 → 출처(PMID) 표시 (시나리오 5)
- 특허 텍스트 붙여넣기 → `SEQ ID NO` 후보 추출 → 채택 → 특허번호·SEQ ID NO 기록 (시나리오 6)
- 티타늄 등 언급이 있는 초록에서 결합 대상 후보가 제안되고, 확정 후 서열 헤더 요약에 표시된다. 언급이 없으면 "미보고" (시나리오 6c)
- 발굴 방법을 고르지 않으면 "미보고", 변이체는 "설계된 서열(비실험)" (시나리오 6b)
- 비표준 문자 포함 입력에서 경고와 원문 메모가 유지된다 (시나리오 7)
- 자동으로 채택되는 값이 없다 (모든 채택은 사용자 클릭)

## 테스트
- `seqextract.py`: 1문자/3문자 표기, `SEQ ID NO` 패턴, 오탐 제외(일반 대문자 단어, 약어, DNA 서열), 비표준 문자 탐지
- `binding.py`: 키워드·동의어 매칭(대소문자), 매칭 없음 → 빈 후보, 여러 소재 언급 시 모두 후보로 반환
- `europepmc.py`: fixture 파싱, 결과 0건, 초록 없는 항목

## 리스크
- 추출 오탐/누락 → 후보 표를 항상 사용자가 검토, 서열 수정 가능하게 유지
- 특허 소스 접근 불가 → 붙여넣기 경로를 기본으로 설계
- 저작권: 서열·식별자·1문장 이내 발췌만 저장, 본문 전체는 세션 밖에 저장하지 않는다
- 결합 대상 키워드가 다른 문맥(비교 대조군 소재 등)에서 나옴 → "제안"으로만 표시하고 확정은 사용자가 한다
