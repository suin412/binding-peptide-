## 점검 결과 기록란 (2026-10-02)

검증 수준 표기: **자동** = `pytest` 화면 흐름 테스트(AppTest, 외부 API는 fixture/가짜 응답) · **실제 API** = 실제 외부 서비스로 확인 · **브라우저** = 내장 브라우저에서 화면 확인.

| 시나리오 | 결과 | 비고 |
|---|---|---|
| 1 melittin 검색·물성 | 통과 | 자동 + 실제 API/브라우저(UniProt 검색, 70 aa 전구체와 26 aa 항목 모두 표시). 26 aa 성숙 구간은 "사용할 구간"에서 선택 |
| 2 알라닌 스캐닝·정렬 | 통과 | 자동(K7A 변이체 저장, 동일성 96.2%) + 브라우저(정렬·차이 하이라이트·소수성 플롯·helical wheel 확인) |
| 3 구조 비교 / (선택) RMSD | 통과 | 실제 API(AlphaFold DB, ESMFold) + 브라우저(pLDDT 색상 3D, 변이 잔기 강조). RMSD는 기본 꺼짐, 길이 다르면 비활성화(자동) |
| 3b 가상 스크리닝 (재순위화 on/off) | 통과 | 자동(기본 꺼짐에서 ESMFold 호출 0회, 켜면 부모 1 + 상위 3회). 화면은 브라우저에서 직접 확인하지 않음 |
| 4 400 aa 초과 안내 | 통과 | 자동(API 호출 없이 안내 오류) |
| 5 논문 기반 펩타이드 | 통과 | 자동(가짜 논문) + 실제 API(Europe PMC에서 실제 초록 8건 중 서열·소재 후보가 추출되는 것 확인: 예 RKLPDA/티타늄). 앱 UI에서 실제 검색→채택 전체를 브라우저로 돌려 보지는 않음 |
| 6 특허 경로 | 통과 | 자동(가상 서열목록 `<400>` 블록 → SEQ ID NO 기록). 실제 특허 자동 검색은 미구현(붙여넣기 방식) |
| 6b 발굴 방법 표시 | 통과 | 자동(선택 목록에서 고른 값이 헤더에 반영, 안 고르면 "미보고", 변이체는 "설계된 서열(비실험)") |
| 6c 결합 대상 | 통과 | 자동(제안 → 확정, 소재 언급 없으면 "미보고") |
| 7 비표준 잔기 경고 | 통과 | 자동(Aib/Orn/Ac/-NH2 → 단순화 + 원문 메모 보존) |

점검 중 발견해 고친 문제:
- 한글이 matplotlib 그림에서 네모로 나옴 → 한글 폰트 자동 선택
- 변이체를 만든 뒤에도 구조 탭의 B 선택이 "(없음)"에 고정됨 → 위젯 키에 변이체 수 반영
- 3D 뷰어 iframe에 스크롤바 → 폭 100% + 여백 제거
- 서로 다른 소스(AlphaFold DB vs ESMFold)의 구조 비교가 변이 효과로 오해될 수 있음 → 경고 추가
- `use_container_width`, `st.components.v1.html` 사용 중단 예고 → 새 API로 교체
