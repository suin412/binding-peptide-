1. 개요

PepLab은 논문·특허·UniProt에 알려진 펩타이드/단백질을 찾아 서열과 출처, 발굴 방법, 결합 대상, 보고된 결합 친화도를 함께 기록하고, 결합 대상(표면)에 붙을 것 같은 새 서열을 자동으로 추천받아 물성을 분석해 보는 연습용 앱입니다. 신약 설계 도구가 아니라 흐름을 직접 체험하는 데 목적이 있습니다.

5개화면 탭
6종표면 분류 (폴리머·티타늄·귀금속·실리카·아파타이트·탄소)
281개자동 테스트 (모두 통과)
6개마일스톤 (M1~M6 완료)

가장 중요한 한계: 앱의 점수는 표면별 잔기 가중치로 만든 학습용 휴리스틱이며 결합 친화도(Kd) 예측이 아닙니다. 점수가 오른다고 실제 결합이 좋아진다는 뜻이 아닙니다. 모르는 값은 추측하지 않고 "미보고"로 표시합니다.

2. 앱 화면 구성

🔎 검색→ 🔧 개선형 추천→ 📊 서열 분석→ 🧲 결합 친화도→ 🎯 전체 서열 기반 추천

왼쪽 사이드바에는 내 서열 목록(현재 서열 선택, 삭제, 발굴 방법·결합 대상 편집)과 FASTA/CSV 내보내기가 있습니다. 탭 위쪽에는 현재 서열의 이름·출처·요약 문장이 항상 표시됩니다.

탭하는 일
🔎 검색UniProt 검색, 논문·특허에서 서열 찾기(전문 확인 포함), 직접 입력·프리셋. 채택한 서열에 출처·발굴 방법·결합 대상을 기록
🔧 개선형 추천서열 하나를 골라(또는 직접 입력해) 몇 개 잔기만 바꿔 점수가 오르는 개선형을 추천
📊 서열 분석물성 비교, 서열 정렬, 소수성·조성·helical wheel 그림
🧲 결합 친화도문헌에서 보고된 Kd/Ka/ΔG 기록·단위 변환, 계산값과 측정값 구분, 순위 상관
🎯 전체 서열 기반 추천결합 표면을 고르면 알려진 결합 서열 전체를 참고해 새 서열을 자동 추천

3. 핵심 기능

3.1 검색

  • UniProt: 키워드·ID 검색, 상세 확인, 성숙 구간 선택.
  • 논문 · 특허(Europe PMC): 논문 제목이 아니라 서열이 바로 보이는 방식이 기본입니다. 연도 구간별로 균등하게 검색해 최근 논문에만 치우치지 않게 하고, 초록뿐 아니라 오픈액세스 전문(필요 시 NCBI PMC)도 읽어 서열 후보를 추출합니다. 특허 서열(PAT)과 서열 문자열 자체를 전문에서 찾는 검색도 지원합니다. 논문 이름 검색은 선택 모드입니다.
  • 검색어 보조: PET, PS, PE, PP, PC, PVC, PLA, PMMA, PDMS, HA 같은 약어를 풀어서 검색하고, 서열 후보의 신뢰도(상표명·시약·일반 단어 제외)를 점검합니다.
  • 기록 항목: 출처(PMID·DOI·특허번호), 발굴 방법(선택 목록), 결합 대상(분류·이름·조건), 보고된 친화도. 자동 제안값은 "미검증"으로 구분하고 확정 후 반영합니다. 비표준 요소(D-아미노산, 말단 변형, 비천연 아미노산)는 경고와 함께 메모로 보존합니다.

3.2 🔧 개선형 추천

  • 입력 방식 2가지: ① 검색해서 채택한 내 서열에서 선택, ② 서열 직접 입력(저장 없이도 추천 가능, 개선형을 저장할 때 입력 서열도 부모로 함께 저장).
  • 설정: 결합 표면(서열에 기록된 결합 대상에서 자동 선택), 최대 변이 수(기본 3), 추천 개수, 바꾸지 않을 위치(예: 1-3, 7), 참고할 알려진 서열과 반영 비중.
  • 방식: 부모에서 최대 k개 위치를 치환한 변이체를 빔 탐색(폭 100)으로 훑고, 바꾼 잔기 하나당 2점의 비용을 물려 적게 바꾸는 쪽을 우선합니다. 부모보다 점수가 오른 후보만, 서로 3곳 이상 다르게 고릅니다.
  • 결과: 변경 표기(예 D5R), 부모 대비 점수, 변이별 표면 가중치 변화, 잔기 기여 그림. 오르는 변이가 없으면 "이미 (국소) 최적"이라고 알립니다. 저장하면 부모에 연결된 설계된 서열(비실험)이 됩니다.

3.3 🎯 전체 서열 기반 추천

  • 표면별 알려진 서열 목록(문헌 예시 + 내가 채택해 해당 표면 결합으로 기록한 서열)을 보여주고, 참고할 서열을 고르게 합니다.
  • 방식: 유전 알고리즘으로 후보를 만들고, 점수 = 표면 점수 + 알려진 서열과의 유사도(잔기 구성 + 연속 2잔기 모티프) − 제약 벌점(용해도·응집·Cys·연속 잔기 등). 알려진 서열을 섞은 재조합에서 탐색을 시작하며, 80% 이상 같은 복사본은 제외하고 서로 잔기 구성이 다른 후보를 고릅니다. 같은 설정이면 결과가 재현됩니다.
  • 기준선 확인: 알려진 서열 자신의 점수를 함께 보여주고, 점수가 낮은 표면(티타늄)에서는 경고합니다.
  • 문헌 서열 예시: 폴리머 4개(PET·PE·PP·PS 설계 서열), 티타늄 3개(TBP-1, TiBP1, TiBP2).

3.4 두 추천 탭 공통

결과 아래에서 저장하지 않아도 전체 후보의 물성(분자량·pI·순전하·GRAVY·불안정성 지수)을 비교할 수 있습니다(개선형 추천에서는 부모도 함께 표시). 구조 예측 기능은 없습니다.

3.5 📊 서열 분석 · 🧲 결합 친화도

  • 서열 분석: 물성 비교, 서열 정렬(동일성·차이 위치), 소수성 플롯·조성·helical wheel.
  • 결합 친화도: Kd/Ka/ΔG 변환(ΔG = RT ln Kd, 298 K), 문헌 보고값과 계산값의 구분, 본문에서의 값 후보 추출, 앱 점수와 보고값의 Spearman 순위 상관.

3.6 엑셀 내보내기

  • 사이드바와 각 탭의 📥 전체 결과 엑셀(.xlsx) 내보내기 버튼으로 한 파일을 내려받습니다.
  • 시트: 안내 · 내 서열 · 결합 성향 점수 · 결합 친화도 · 예측 vs 보고값 · (실행했다면) 개선형 추천 · 전체 서열 기반 추천 · 참고한 알려진 서열 · 논문 검색 결과. 모든 결과가 한 파일에 들어가고, 추천은 여러 번 실행해도 실행 번호·시각 열과 함께 한 시트에 쌓입니다(앱을 끄면 기록은 사라짐).
  • 추천 결과를 내 서열에 저장하지 않아도 내보낼 수 있고, 엑셀 라이브러리 없이 앱이 .xlsx를 직접 만듭니다(표준 구조를 XML 파서로 되읽어 검증했으며, 실제 Excel에서 열어 본 확인은 별도로 필요).

4. 점수 방식과 한계

표면 결합 성향 점수: 표면 6종(폴리머, 티타늄, 귀금속, 실리카, 아파타이트, 탄소)마다 잔기별 가중치를 두고, 서열의 점수를 무작위 서열과 비교한 백분위와 0~100으로 환산한 점수로 표시합니다. 추천에서는 포화되지 않는 환산 점수를 씁니다.

항목실제 평가 결과
결합할 법한 서열 구분비교적 잘함 (무작위 서열보다 확실히 높은 점수)
결합 세기 순위잘 못함 — 점수가 오른다고 Kd가 좋아진다는 뜻이 아님
티타늄문헌의 알려진 Ti 결합 서열이 이 점수에서 낮게 나옴 → 기준선이 약하다는 경고 표시
이미 좋은 서열개선 후보가 거의 없거나 "이미 국소 최적"으로 보고됨 (거짓 개선을 만들지 않음)
반영하지 못하는 것서열 순서 전체, 3D 구조, pH, 이온 세기. 보고된 친화도 값은 추천에 쓰이지 않음

MD(분자동역학) 예측값은 제공하지 않습니다. 표면 결합 에너지 계산에는 표면 모델과 힘장 준비, 수 시간의 계산이 필요해 앱 안에 넣지 않았습니다. 추천된 서열을 MD 입력 파일로 내보내는 방안은 아직 결정 전입니다(8장).

5. 개발 과정

5.1 마일스톤

단계내용상태
M1 골격탭 구조, SeqRecord 데이터 모델, 프리셋, 입력 검증완료
M2 UniProt 검색검색·상세·성숙 구간 선택, 출처 기록, 물성 표시완료
M3 논문·특허서열 후보 추출(1문자/3문자/SEQ ID NO), 발굴 방법·결합 대상 기록, 비표준 경고완료
M4 설계·스크리닝변이 설계, 정렬, 그림, 필터 깔때기·점수·순위 (이후 추천 중심으로 재설계)완료
M5 구조AlphaFold DB, ESMFold, 3D 뷰어 (이후 구조 탭과 구조 예측 화면을 모두 제거)완료
M6 마감README, 오류 처리, 디스크 캐시, 점검완료

5.2 사용자 요청에 따른 주요 변경

  1. 논문 검색 방식 변경(2026-10-02): 논문 제목 선택 단계 없이 서열이 바로 보이게 하고 전 기간 논문을 대상으로 함. 기본 정렬이 최근 논문에 치우쳐 있던 문제를 연도 구간별 균등 검색으로 해결.
  2. 검색 정확도 개선: "PET binding peptide" 같은 질의가 대상 결합 서열을 찾도록 약어 확장, 초록뿐 아니라 전문 확인, 서열 문자열 전문 검색 추가.
  3. 결합 친화도 탭 추가: 표면/소재 대상, 보고값 기록과 앱 점수 비교(Spearman).
  4. 설계 방식 전환: 무작위·변이 서열을 직접 만드는 화면을 없애고, 대상과의 결합 성향이 높을 서열을 자동으로 추천하는 방식만 남김.
  5. 새 서열도 바로 분석: 저장하지 않아도 추천 결과의 물성을 바로 확인.
  6. 추천 탭 2개로 분리(2026-10-12): 개선형 추천 + 알려진 전체 서열 기반 추천, 구조 탭 제거, 유사도에 2-mer 모티프 추가.
  7. 엑셀 내보내기와 휴대용 패키지: 결과 전체를 .xlsx 한 파일로 내보내는 버튼 추가, 파이썬 없이 실행하는 휴대용 폴더(PepLab 실행.bat) 제공.
  8. 구조 예측 기능 제거: 추천·분석 탭의 ESMFold 구조 예측도 없애 사용자 요청에 따라 앱이 외부 구조 서버 없이 동작하게 함.
  9. 개선형 입력 방식 확장: 채택한 서열에서 선택 / 직접 입력 두 가지. 탭 순서를 전체 서열 기반 추천이 마지막이 되도록 변경.

5.3 점검 중 발견해 고친 문제

  • 새로 추가·저장한 서열이 현재 서열로 선택되지 않던 버그 (사이드바 선택이 이전 값을 덮어씀).
  • 서열을 추가하면 화면이 첫 탭으로 되돌아가던 문제 (탭 위쪽 요소를 하나의 고정 컨테이너로 묶어 해결, 브라우저에서 확인).
  • 추천 후보가 모두 같은 잔기 구성이 되던 문제 → 구성 거리 기준 다양성 선택.
  • 점수가 0에서 잘려 개선 폭이 안 보이던 문제 → 실제 값(음수 가능) 표시.
  • 입력 위젯의 기본값이 첫 실행 값에 고정되던 문제 → 위젯 키에 맥락을 포함.

6. 기술 구조

app.py                  Streamlit 진입점 (사이드바 + 5개 탭)
src/
  sources/              UniProt, Europe PMC, 서열 후보 추출, 검색어 보조, 결합 정보, 디스크 캐시
  analysis/             물성, 정렬, 그림, 표면 결합 점수(binding_score)
  design/               recommend.py (전체 서열 기반 추천), improve.py (개선형 추천)
  structure/            (화면에서 쓰지 않음) ESMFold, PDB 유틸, 3D 뷰어 코드
  export.py             엑셀(.xlsx) 내보내기 (외부 라이브러리 없음)
  ui/                   탭별 화면, 공용 물성 표(structure_view.py), 세션 상태
tests/                  281개 테스트 (로직 단위 테스트 + Streamlit AppTest 화면 흐름)
docs/                   PRD, PLAN, development/ (마일스톤 문서), 이 보고서
외부 서비스용도
UniProt REST서열·메타데이터 검색
Europe PMC REST논문·특허 검색, 오픈액세스 전문, 서열 문자열 전문 검색
NCBI PMC전문 가져오기 보조 경로

화면에서는 쓰지 않지만 코드는 보존한 모듈: 변이 생성(design/mutate.py), 스크리닝 깔때기(analysis/screen.py), AlphaFold DB 조회(sources/alphafold.py), 구조 비교·RMSD(structure/compare.py), ESMFold 클라이언트(structure/esmfold.py).

설계 원칙: 화면과 로직 분리(로직은 Streamlit 없이 테스트), 외부 API 호출은 테스트에서 mock, 응답은 TTL 디스크 캐시(실패는 캐시하지 않음), 같은 설정이면 결과가 재현되는 추천.
